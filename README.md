# 졸업사정 자가체크 (가톨릭대학교 특수교육과)

입학년도와 이수 유형을 고르고 과목을 체크하면, 졸업 요건을 얼마나 채웠는지 한눈에 보여주는 웹 앱입니다.

> **이 페이지는 Claude(Anthropic의 AI)와 함께 만들었습니다.**
> 학과에서 사용하던 스프레드시트 자가체크 리스트를 웹으로 옮긴 것이며, 졸업 요건을 계산하는 방식에 오류가 있을 수 있습니다.
> **참고용으로만 사용하고, 정확한 내용은 학과 홈페이지 확인과 학과 조교 상담으로 확인하세요.**

- 서버 없이 브라우저에서만 동작합니다. 입력한 내용은 학생의 브라우저에만 저장되고 어디로도 전송되지 않습니다.
- 사용 기술: React, JavaScript, Vite
- 배포 방식: GitHub Pages 주소 접속, 또는 HTML 한 파일 내려받기

---

## 1. 한눈에 보는 동작 방식

```
 ┌──────────────┐     ┌──────────────────┐     ┌──────────────────┐
 │  rules/      │     │  학생이 입력       │     │  logic/           │
 │  학점 기준    │     │  (과목 체크 등)    │     │  졸업 판정 함수    │
 │  과목 목록    │──┐  │  = 저장되는 값     │──┐  │                  │
 └──────────────┘  ├─▶└──────────────────┘  ├─▶│ 이수 여부 · 부족분 │──▶ 화면
                   │                         │  └──────────────────┘
                   └─────────────────────────┘
```

핵심 원칙은 세 가지입니다.

1. **기준(데이터)과 판정(로직)과 화면을 분리했습니다.** 학점 기준이 바뀌어도 데이터 파일만 고치면 되고, 판정은 화면 없이 테스트할 수 있습니다.
2. **저장하는 것은 "학생이 입력한 값"뿐입니다.** "이수/미이수" 같은 결과는 저장하지 않고 화면을 열 때마다 새로 계산합니다. 규칙을 고쳐도 저장된 값과 결과가 어긋나지 않습니다.
3. **판정 로직은 화면과 무관한 순수 함수입니다.** 같은 입력을 넣으면 항상 같은 결과가 나오므로 `npm test`로 자동 검증됩니다.

## 2. 폴더 구조와 각 파일의 역할

```
Graduation/
├─ index.html                  브라우저가 처음 여는 파일 (화면 모드 초기 적용 포함)
├─ vite.config.js              빌드 설정 (일반 빌드 / HTML 한 파일 빌드)
├─ package.json                명령어와 사용 패키지
├─ scripts/checkRules.mjs      규칙 데이터의 학점 합계 점검 스크립트
├─ .github/workflows/deploy.yml  GitHub Pages 자동 배포 설정
└─ src/
   ├─ main.jsx                 시작점
   ├─ App.jsx                  어떤 화면을 보여줄지 결정
   ├─ index.css                전체 스타일 (다크모드·밝은 화면·모바일·인쇄)
   ├─ rules/                   ① 기준 데이터
   ├─ logic/                   ② 졸업 판정
   ├─ storage/                 ③ 저장·백업
   ├─ hooks/                   ④ 상태 관리
   └─ components/              ⑤ 화면
```

### ① `src/rules/` — 기준 데이터

졸업 기준이 바뀌면 **이 폴더만 고치면 됩니다.** 코드를 몰라도 숫자와 과목명만 바꾸면 되도록 주석을 달아 두었습니다.

| 파일 | 내용 |
|---|---|
| `courses.js` | 전공 과목(코드·학점·영역·기본이수 여부·중복 인정 가능 여부·필수 여부), 교직 과목, 교직실무처럼 "하나만 선택"하는 과목 묶음 |
| `liberalArts.js` | 입학년도별 기초교양 필수 과목, 중핵교양 영역별 최소 학점, 선택 가능한 입학년도 목록과 기본값(올해 − 3) |
| `requirements.js` | 총 130학점, 특수교육 42학점, 직업교육 39학점, 중복 인정 한도(5과목 15학점), 이수 유형 4가지, 교직 기준, 횟수 요건(적성검사 등), 졸업 인증 안내, 학과 연락처와 안내 주소 |

### ② `src/logic/` — 졸업 판정 (화면과 무관한 순수 함수)

| 파일 | 역할 |
|---|---|
| `studentState.js` | 학생이 입력하는 값의 모양(체크한 과목, 총 학점, 중핵교양 입력 등)과 기본값 |
| `major.js` | **특수교육 · 표시과목(직업교육) · 전공 학점** 판정. 중복 인정 때문에 서로 얽혀 있어서 한 파일에서 계산 |
| `liberalArts.js` | 기초교양 · 중핵교양 · 전공기초 판정 |
| `teaching.js` | 교직과정 판정 (소양·이론·실습·횟수 요건) |
| `evaluateGraduation.js` | 위 판정들을 모아 요건 9개(복수전공 직업교육은 10개)의 이수 여부를 한 번에 계산 |
| `summary.js` | 요건별 한 줄 요약("기본이수 7 / 7과목")과 "아직 남은 일" 문구 |
| `overview.js` | 체크한 과목을 영역별로 정리한 "한눈에 보기" 데이터 |
| `utils.js` | 학점 합계, 이수 유형 찾기 같은 작은 도우미 |
| `*.test.js` | 판정 테스트 (30개) |

### ③ `src/storage/` — 저장과 백업

| 파일 | 역할 |
|---|---|
| `studentStorage.js` | 브라우저 `localStorage`에 입력을 저장·불러오기. 백업 파일(JSON)로 내보내기·불러오기. 저장된 값이 깨졌거나 버전이 다르면 안전하게 처음 상태로 시작 |

### ④ `src/hooks/` — 상태 관리

| 파일 | 역할 |
|---|---|
| `useStudentState.js` | 학생 입력을 들고 있다가, 바뀔 때마다 자동 저장 |
| `useTheme.js` | 다크모드(기본) ↔ 밝은 화면 전환과 기억 |

### ⑤ `src/components/` — 화면

| 파일 | 역할 |
|---|---|
| `IntroScreen.jsx` | 첫 안내 화면 (참고용 안내, 학과 홈페이지·조교 상담 안내) |
| `SetupScreen.jsx` | 입학년도(목록)와 이수 유형 선택 |
| `Dashboard.jsx` | 요건 현황, 진행률, 아직 남은 일, 체크 내역, 백업, 인쇄 |
| `TopBar.jsx` | 모든 화면 위쪽: 처음으로 / 졸업요건 확인 링크 / 화면 모드 전환 |
| `RequirementPage.jsx` | 요건별 체크 화면의 공통 틀 |
| `pages/*.jsx` | 요건별 체크 화면: 총 학점, 기초교양, 중핵교양, 전공기초, 표시과목, 특수교육, 전공 학점, 교직, 제2전공, 졸업 인증 |
| `CourseCheckRow.jsx`, `StatusLine.jsx`, `DuplicationNotice.jsx`, `SecondMajorPanel.jsx`, `CourseOverview.jsx`, `BackupPanel.jsx` | 여러 화면에서 같이 쓰는 부품 |

`App.jsx`의 `requirementPages` 표에 "요건 id → 화면"이 한 줄씩 적혀 있어서, 새 체크 화면을 만들면 한 줄만 추가하면 됩니다.

## 3. 졸업 판정 규칙 (요약)

요건은 모두 `evaluateGraduation()` 한 함수에서 계산됩니다.

| 요건 | 판정 방식 |
|---|---|
| 총 이수 학점 | 학생이 입력한 학점 ≥ 130 |
| 기초교양 | 입학년도별 필수 과목을 모두 체크 (학생이 과목을 추가·삭제·수정할 수 있음) |
| 중핵교양 | 영역마다 최소 학점 이상 + 전체 합계 ≥ 총 학점 (남는 학점은 아무 영역이나 가능). 2024학번만 글로벌·외국어 5학점 이상 |
| 전공기초 | 장애의이해와재활 + 사회과학 계열 3학점 + 사회과학 외 계열 3학점 |
| 표시과목(직업교육) | 기본이수 7과목 21학점 + 교과교육 9 + 교육과정 9 = 39학점, 필수 과목 |
| 특수교육 | 기본이수 7과목 21학점 + 전체 14과목 42학점, 필수 과목 |
| 특수교육 + 표시과목 학점 | 성적표 기준 학점(중복 인정 과목은 한 번만 계산) ≥ 66 (제1전공심화) |
| 교직과정 | 소양 6 + 이론 12 + 교육실습(2과목 4학점, 복수전공 3과목 6학점) + 횟수 요건 |
| 졸업 인증 | 학생이 "통과했다"고 체크 |

### 중복 인정

직업교육 39학점과 특수교육 42학점을 합치면 81학점이지만, 양쪽에서 동시에 인정되는 과목(최대 5과목 15학점)이 있어서 성적표에 쌓이는 학점은 81 − 15 = **66학점**입니다.

- 표시과목(직업교육)에서 체크한 과목 중 중복 대상은 **특수교육에도 자동 인정**됩니다.
- 특수교육 과목을 표시과목으로도 인정받으려면 학생이 직접 고릅니다.
- 한도를 넘으면 초과분은 인정하지 않고 화면에서 경고합니다.
- **특수교육대상학생진단및평가**는 특수교육/직업교육 기본이수 중 **체크한 쪽**에서 인정됩니다. 직업교육에서 선택하면 특수교육에는 자동 인정(중복)으로만 들어갑니다.

### 특별 처리

- **마약류 중독 여부 검사**: 마지막 학기에 받는 항목이라 교직과정 이수 판정에서는 제외하고, 경고만 계속 보여줍니다.
- **복수전공의 제2전공**: 이수 기준이 학과마다 달라서 판정하지 않고, 학생이 학과에 확인한 뒤 직접 체크합니다.
- **기준이 없는 새 학번**: 가장 최근 학번의 기준을 대신 적용하고 화면에서 알려줍니다.

## 4. 화면 흐름

```
안내 화면 → 입학년도·이수 유형 선택 → 요건 현황 ──▶ 요건별 체크 화면
  (처음 한 번)                          │   ▲            (체크하면 바로 반영)
                                        │   └─ 완료/뒤로
                                        ├─ 체크한 과목 한눈에 보기 (인쇄 시 자동 펼침)
                                        ├─ 입력 내용 백업 (파일 저장/불러오기)
                                        └─ 인쇄 / PDF 저장

상단 바(모든 화면): [← 처음으로]   [졸업요건 확인 ↗] [☀️/🌙 화면 모드]
```

입학년도나 이수 유형을 바꾸려면 **처음으로**를 누릅니다. 입력한 정보가 모두 초기화된다는 경고가 먼저 나옵니다.

## 5. 자주 쓰는 명령어

PowerShell에서는 `npm` 대신 `npm.cmd`를 쓰세요. (실행 정책 때문에 `npm`이 막혀 있을 수 있습니다)

| 명령어 | 하는 일 |
|---|---|
| `npm.cmd install` | 필요한 패키지 설치 (처음 한 번) |
| `npm.cmd run dev` | 개발용 서버 실행 → 브라우저에서 `http://localhost:5173/` |
| `npm.cmd test` | 졸업 판정 로직 테스트 |
| `npm.cmd run check:rules` | 규칙 데이터의 학점 합계가 서로 맞는지 점검 |
| `npm.cmd run build` | 웹페이지 빌드 → `dist/` (GitHub Pages용) |
| `npm.cmd run build:single` | HTML 한 파일 빌드 → `dist-single/index.html` (학생 배포용) |

## 6. 졸업 기준이 바뀌었을 때

1. `src/rules/` 의 해당 파일에서 숫자나 과목을 고칩니다.
2. `npm.cmd run check:rules` 와 `npm.cmd test` 로 오류가 없는지 확인합니다.
3. 새 학번 기준이 생기면 `liberalArts.js`의 표(`basicLiberalArts`, `coreLiberalArts`)에 그 학번을 한 줄 추가합니다.
4. 배포합니다. (아래 참고)

## 7. 배포

### 방법 1. GitHub Pages (학생들이 주소로 접속)

`main` 브랜치에 코드를 올리면 `.github/workflows/deploy.yml` 이 자동으로 **테스트 → 빌드 → 배포**합니다. 테스트가 실패하면 배포되지 않습니다.

처음 한 번만 필요한 설정:

1. GitHub에서 새 저장소를 만든다. (Public, README·.gitignore는 체크하지 않음)
2. 저장소의 `Settings` → `Pages` → `Build and deployment` → `Source` 를 **GitHub Actions** 로 바꾼다.
3. 이 폴더의 코드를 저장소에 올린다.

```
git init -b main
git add .
git commit -m "졸업사정 자가체크 첫 버전"
git remote add origin https://github.com/<내 아이디>/<저장소 이름>.git
git push -u origin main
```

이후 수정할 때마다:

```
git add .
git commit -m "무엇을 고쳤는지 한 줄로"
git push
```

배포 주소: `https://<내 아이디>.github.io/<저장소 이름>/`
진행 상황은 저장소의 `Actions` 탭에서 볼 수 있고, 초록색 체크가 뜨면 완료입니다. (보통 1~2분)

### 방법 2. HTML 한 파일 (학생이 내려받아 사용)

`npm.cmd run build:single` 을 실행하면 `dist-single/index.html` 하나가 만들어집니다. (약 290KB)
이 파일을 학생들에게 전달하면 더블클릭만으로 인터넷 없이도 쓸 수 있습니다.

GitHub Pages로 배포하면 같은 파일이 `https://<내 아이디>.github.io/<저장소 이름>/graduation.html` 에도 함께 올라가므로,
이 주소를 공유해서 내려받게 할 수도 있습니다.

### 알아둘 점

- 입력 내용은 **브라우저마다 따로** 저장됩니다. 다른 기기로 옮기려면 현황 화면의 "파일로 저장 / 파일에서 불러오기"를 쓰세요.
- HTML 파일을 다른 폴더로 옮기면 브라우저가 다른 사이트로 보아 저장된 입력이 보이지 않을 수 있습니다. 이때도 백업 파일로 옮기면 됩니다.

## 8. 만든 과정

이 앱은 사용자가 단계별로 직접 실행해 확인하면서 Claude와 함께 만들었습니다.

1. 프로젝트 생성 → 2. 규칙 데이터 정리 → 3. 판정 로직과 테스트 → 4. 입학년도·이수 유형 선택과 저장
→ 5. 요건별 체크 화면 → 6. 결과 요약·백업·인쇄 → 7. 화면 다듬기(다크모드, 모바일) → 8. 배포 설정

기존 스프레드시트 자가체크 리스트와 학과 학사정보 페이지(<https://sped.catholic.ac.kr/sped/course/academic.do>)를 기준으로 했으며,
학교 기준과 다른 부분이 있다면 `src/rules/` 의 데이터를 고쳐 주세요.
